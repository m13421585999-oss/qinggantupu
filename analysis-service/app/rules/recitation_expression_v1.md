# 朗诵表达分析规则 v1.0

本服务第一版只输出声音事实，不自动生成教学标签。下列规则随“复制分析结果”提示一起交给 ChatGPT 解释。

- 重音是表达焦点，不等于音量更大；结合语义、时长、音高、速度、音色、虚实和前后反差判断。
- 停顿分短停 `/` 与长停 `///`；实际声音与意群优先，标点只作参考，长短是局部相对概念。
- 拖音是某字或音节相对局部速度明显延长，主要依据 `local_duration_ratio`。
- 语势只分 `peak / valley / rising / falling`，是局部文字区间的宏观声音运动；输出 `active_span / core_zone / strength / confidence`，并降低普通话单字声调干扰。
- 句尾语调只分 `rising / falling / level`，与宏观语势独立。
- 节奏只分轻快、凝重、舒缓、紧张、高亢、低沉，综合语速、停顿、力度、音高变化、连贯性与文本表达判断。
