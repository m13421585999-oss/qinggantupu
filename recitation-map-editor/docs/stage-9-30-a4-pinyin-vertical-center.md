# Stage 9.30 · A4 拼音层最终高度居中修复

本阶段修复 9.29 中拼音层偏上的问题。

## 问题原因

之前拼音层使用了固定的 `flex-start` 和 `translateY(-.25mm)`，这会在分页、页面密度、行高、字号都已经自适应之后，仍然按旧的固定偏移来定位拼音，导致拼音偏上。

## 新逻辑

按照和语势层一致的顺序处理：

```text
文稿输入
→ token 化
→ 分行
→ 分页
→ 根据每页行数计算页面密度
→ 确定拼音层最终高度
→ 在拼音层最终上边界 / 下边界之间垂直居中拼音
→ 渲染
```

## 实现

- `.pinyin-row` 改为 `align-items: center`。
- `.pinyin-token` 使用最终行高的 `height: 100%`。
- `.pinyin` 移除向上的 transform。
- 通过最终的 `--pinyin-row-h` 完成居中，而不是提前写死 top 偏移。

## 保留

- 文稿层字号放大逻辑保留。
- 语势层自然曲线逻辑保留。
- 分页、放大、打印皮肤不变。
