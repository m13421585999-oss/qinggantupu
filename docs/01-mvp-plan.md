# 朗诵情感图谱 · 产品一 MVP 执行清单

## 1. 第一版边界

第一版只完成一条闭环：

> 文稿 + 优质参考朗诵 + 系统内置朗诵知识库 → 反向分析 → 可编辑控制谱 → AI 示范音频 → 发布 → 用户看谱、听谱、逐字跟随。

本版明确不做：用户录音、自动评分、纠错建议、练习历史、社交、付费和大规模内容运营。

## 2. 冻结的产品规则

- 三层图谱固定为：拼音层、文稿层、语势层。
- 四种语势固定为：波峰、波谷、起潮、落潮。
- 句尾语调固定为：上扬、下抑、平收。
- 文稿层使用：红字表示表达焦点，`/` 表示短停，`///` 表示长停，`——` 表示拖音。
- 红字不等于“大声读”；重音实现方式和声音质感保存在隐藏字段中。
- 一个图谱句只有一个主要语势、一个句尾语调，可以有多个焦点和停顿。
- 节奏固定为：轻快、凝重、舒缓、紧张、高亢、低沉。
- 参考朗诵是图谱的声音依据；没有参考朗诵时不得生成标准情感图谱，第一版不提供纯文本自动图谱。
- 朗诵知识库由系统默认调用，当前作品创建流程不提供上传、选择或版本切换入口。
- 参考朗诵与 AI 示范是两条不同音轨，分别拥有自己的字符/词时间轴。
- 图谱、编辑器、TTS、时间轴和发布页只认同一份版本化控制谱，不直接编辑图片。

## 3. 可执行任务

### M0：产品契约与可运行纵向切片（本轮完成）

- [x] 冻结 MVP 边界和图谱语义。
- [x] 定义控制谱 v1.1、作品、独立音轨、时间轴和任务状态。
- [x] 确定 Web、音频分析、LLM、TTS、存储之间的边界。
- [x] 创作端只录入作品名称、作者/来源、完整正文和一份参考朗诵。
- [x] 无参考朗诵时禁止解析；解析动作生成四句演示控制谱初稿。
- [x] 图谱卡片直接打开单句面板，完成节奏、语势、强度、重音、停顿、句尾语调和拖音编辑。
- [x] 拼音展示改为声调符号，机器拼音保留在底层。
- [x] 拼音、正文、语势共享字符索引，并按实际 DOM 坐标绘制曲线。
- [x] 可独立生成占位 AI 示范及其字符时间轴，再进入预览发布。
- [x] 观看端可整篇/单句播放、点击句子跳转、倍速、逐字高亮和查看三层图谱。
- [x] 教师口令、声音质感、置信度和实现方式保留在数据层但不出现在主界面。

验收：不接外部 AI 也能完整演示“创建—编辑—生成—发布—观看”流程；所有界面由同一份控制谱驱动。

### M1：真实素材入库与持久化

- [ ] 作品 CRUD、草稿/审核/已发布状态。
- [ ] 参考音频和 AI 示范音频持久化；正文直接作为作品字段保存。
- [ ] 系统级知识库独立管理，不进入单篇作品创建流程。
- [ ] 结构化数据写入 D1；音频和文档写入 R2。
- [ ] 文件格式、大小、时长、音频可解码性和正文匹配度检查。
- [ ] 控制谱保存版本，支持回滚和发布版本锁定。

验收：刷新、换设备或重新登录后作品仍存在；已发布作品不受后续草稿修改影响。

### M2：参考朗诵反向分析

- [ ] 音频预处理：采样率统一、响度检查、可选人声分离。
- [ ] 中文转写与文稿强制对齐，输出字符级时间戳。
- [ ] 提取停顿、字符时长、F0、能量、语速和声音质感候选特征。
- [ ] 结合全文语义、体裁和知识库，生成控制谱初稿。
- [ ] 为每个自动字段保存置信度、证据来源和模型版本。
- [ ] 低置信度结果进入人工复核清单。

验收：首篇 1～3 分钟真实作品可得到完整时间轴；随机抽查字符对齐误差的中位数目标不高于 120 ms，句界误差不高于 250 ms。

### M3：生产级图谱编辑器

- [x] 文字点击选择/取消表达焦点。
- [x] 在字符间循环添加、切换和删除短停/长停。
- [x] 修改四种语势、三级强度；焦点变化同步更新语势锚点范围。
- [x] 修改三种句尾语调、六种节奏和拖音。
- [ ] 增加主/次重音及锚点范围的高级编辑入口。
- [ ] 增加特殊读音管理；教师口令和声音质感继续作为隐藏字段。
- [ ] 自动校验：锚点必须在句内、时间轴不重叠、图谱句连续、发布前无阻塞错误。

验收：教研人员无需修改 JSON；任意编辑立即反映到图谱、TTS 编译预览和发布预览。

### M4：AI 示范音频

- [ ] 控制谱编译器：统一谱 → Eleven v3 提示词。
- [ ] 接入 Voice、Natural 稳定度、Pronunciation Dictionary 和时间戳接口。
- [ ] 按图谱句生成但保留上下文，避免句间人物状态漂移。
- [ ] 同一控制谱生成 2～3 个候选，保留人工选择入口。
- [ ] 保存供应商、模型、Voice、Prompt、随机结果和成本记录。
- [ ] 预留 Fish/Qwen 适配器接口。

验收：示范音频与正文完全一致，字符级时间戳可用；重新生成不会覆盖已发布版本。

### M5：发布与观看端

- [ ] 作品库、作品详情和稳定分享地址。
- [x] 大字号三层图谱，适合中老年用户阅读。
- [x] 整篇播放、暂停、拖动、倍速和单句播放。
- [x] 当前句和当前字按音频时间戳高亮；播放结束状态正确复位。
- [x] 点击句子或图谱区域跳到对应音频。
- [x] 观看端不显示编辑控件、知识库、教师口令和内部参数。
- [x] 当前纵向切片已完成桌面与手机响应式适配及键盘操作。

验收：发布作品首次打开即可理解“怎么看、怎么听”；音频跳转误差不高于 150 ms。

### M6：上线前可靠性

- [ ] 创作端权限、发布权限和操作审计。
- [ ] 上传安全、速率限制、失败重试、超时和幂等。
- [ ] AI 任务可恢复，失败不丢原始素材。
- [ ] 真实作品版权、参考朗诵授权、Voice 使用权确认。
- [ ] 成本看板和单篇作品生产耗时记录。

## 4. 推荐交付顺序

1. 先用一篇真实作品校准数据结构和编辑交互。
2. 再打通参考音频反向分析，人工修正优先于追求 100% 自动。
3. 控制谱稳定后接 Eleven；图谱 JSON 与具体 TTS 供应商解耦。
4. 连续完成 10 篇作品后，再判断哪些编辑动作值得继续自动化。

## 5. 第一版完成定义

一篇作品只有同时具备以下内容，才算“可发布”：准确正文、完整控制谱、可播放示范音频、字符级时间轴、通过校验的三层图谱、已锁定发布版本。
