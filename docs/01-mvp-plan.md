# 朗诵情感图谱 · 单人正式版清单

## 产品边界

当前只服务一名创作者，完成以下闭环：

> 本地参考朗诵分析 → ChatGPT 人工解释 → 在线导入控制谱 → 图谱编辑 → AI 示范 → 发布与同步播放。

第一版不做用户录音、评分、陪练、多用户权限、云端 Python、LLM API、复杂任务队列或多家声音供应商。

## 已冻结的规则

- 本地分析只输出声音事实，不把 F0、时长或音量直接当成教学标签。
- 网站正文是唯一权威文本；控制谱 token 必须逐字、逐 index 与正文一致。
- 四种语势：波峰、波谷、起潮、落潮；使用局部 `active_span` 和 `core_zone`。
- 三种句尾语调：上扬、下抑、平直。
- 六种节奏：轻快、凝重、舒缓、紧张、高亢、低沉。
- 红字代表表达焦点，不等于更大音量；`/`、`///`、`——` 分别显示短停、长停和拖音。
- 拼音、正文和语势共享 token index，SVG 不保存固定像素。
- 生产流程没有固定控制谱，也不会在失败时回退到 Demo 数据。

- [x] Windows `setup.bat` 自动建立 Python 环境并准备 FFmpeg。
- [x] `启动朗诵分析.bat` 一键打开 Tkinter 工具。
- [x] ElevenLabs Forced Alignment 字符/词时间戳。
- [x] Parselmouth 时长、局部时值比、F0、音高归一化、强度、停顿和宏观曲线。
- [x] 紧凑 `analysis-result.json`、自动保存、复制和下载。
- [x] `.env`、虚拟环境和输出文件不进入 Git。

### 在线创作

- [x] D1 保存作品正文与控制谱版本。
- [x] 直接粘贴导入 ChatGPT 返回的控制谱。

- [x] 点击句子编辑重音、停顿、拖音、语势、句尾语调和节奏。

## 完成一篇作品的条件

准确正文、对应分析包、通过校验的完整控制谱、人工确认图谱、可播放 AI 示范及其字符时间轴均齐备后，作品才可发布。
