# 朗诵情感图谱 · 正式版执行清单

## 产品边界

当前服务单一创作者，完成：

> 真实正文与真人参考朗诵 → Voice Changer 标准 AI 声音 → 同一声音的对齐、声学分析与 LLM 解释 → 图谱编辑 → 发布与同步播放。

第一版不做用户录音、评分、陪练、多用户协作、复杂消息队列、多家声音供应商或声学实验室级参数。

## 核心约束

- 当前作品 control_spec 只能来自当前作品的正文、音频、声音证据、系统规则和人工编辑。
- 重音是表达焦点；停顿与拖音使用相对证据；语势是局部区间并与普通话单字声调、句尾语调分开。
- 拼音、正文和语势共享 token index，语势 SVG 不保存固定像素。
- 生产流程没有固定控制谱或失败 fallback。
