# 开始真实作品生产前所需输入

## 现在必须提供

### 1. 首篇作品信息与完整正文

- 作品名称、作者/来源（可选）和准确正文。
- 建议朗诵长度 1～3 分钟；首篇不要过长。
- 正文必须与参考音频逐字对应；版本差异需要明确标注。
- 请同时确认作品文本的使用/发布权限。

### 2. 对应的优质参考朗诵

- 推荐 WAV、M4A 或高质量 MP3。
- 单人、普通话清晰、尽量无混响和背景音乐、不削波。
- 如果有配乐也可提供，但请同时提供纯人声版（如果有）。
- 请说明朗诵者、来源、是否允许系统分析和对外展示。

当前作品创建流程不需要用户上传或选择知识库。系统默认调用“系统朗诵知识库 v1.0”；未来如要更新知识库，应在独立的系统管理流程中完成，不与单篇作品创建混在一起。

## 接通 AI 示范音频前需要

### 3. ElevenLabs 配置

- 一个确定的 Voice 或 Voice ID。
- ElevenLabs API Key，放在项目 Secret/环境变量中，不要发在聊天正文里。
- 模型和稳定度建议：Eleven v3 + Natural。
- 如有特殊读音，提供 Pronunciation Dictionary 或读音清单。

### 4. 声音验收样例

- 至少 3～5 个你认为“读得对”的短句音频。
- 对每句简单说明：焦点在哪里、为什么对、哪些声音质感必须保留。
- 这能校准“自然度优先”与“图谱执行度优先”的取舍。

## 可选但会显著提速

- 你喜欢的视觉参考、图谱草稿、字号和色彩偏好。
- 2～3 篇老师已经人工标注过的作品。
- 面向用户的产品名、品牌名、Logo 和一句话介绍。
- 首批 10 篇作品清单及优先级。

## 暂时不需要

用户录音、评分标准、纠错数据、自训练 TTS 数据、Fish/Qwen 部署、数字人和付费体系都不属于产品一第一版。

## 当前开发采用的非阻塞假设

- 未提供首篇素材前，使用旧讨论中的四句“月光下的中国”演示片段。
- 未提供视觉参考前，按中老年教学产品设计：大字号、暖白底、高对比、少技术感。
- 未提供 Eleven 配置前，参考朗诵与 AI 示范使用项目内占位声音验证交互；两条音轨及其时间轴在数据上保持独立。
