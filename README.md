# 声图 · 朗诵情感图谱

“声图”把优秀朗诵加工成看得懂、听得到、可以反复学习的互动朗诵谱。

当前仓库是产品一的第一条可运行纵向切片，包含：

- 创作端四步工作流：准备作品、编辑图谱、生成示范、预览发布。
- 统一朗诵控制谱 v1.1；作品正文只有一个数据源，系统默认使用内置朗诵知识库 v1.0。
- 未上传参考朗诵时禁止生成标准图谱；当前演示作品自带一段可删除、替换和试听的参考音频。
- 拼音、文稿、语势三层图谱。
- 图谱卡片直接打开单句编辑面板，可修改六种节奏、四种语势、强度、重音、停顿、句尾语调和拖音。
- 机器拼音与展示拼音分离，例如 `xiang3` 在界面显示为 `xiǎng`。
- 拼音、正文和语势共用稳定字符索引；曲线按实际文字位置动态测量，不保存像素坐标。
- 参考朗诵和 AI 示范是两条独立音轨及时间轴。
- 整篇播放、单句播放、句子跳转、倍速和基于字符时间戳的逐字高亮。
- 观看端只读取同一作品的图谱、AI 示范和播放时间轴，不显示创作参数。
- 作品、资产、控制谱版本、音频版本、发布版本和处理任务的数据表与迁移。

当前示范使用四句“月光下的中国”片段和项目内占位声音，完整验证“参考音频 → 图谱 → 人工修正 → AI 示范 → 观看端”流程。真实音频分析和 TTS 接口仍是后续接入点。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

检查：

```bash
npm run build
npm run lint
npx tsc --noEmit
npm test
```

数据结构变更后生成迁移：

```bash
npm run db:generate
```
